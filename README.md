# PanchayatMausam — SIH26074
**AI-Based Hyperlocal Weather Downscaling & Agro-Advisory System for Indian Gram Panchayats**

Developed for **Smart India Hackathon (SIH26074)**: *Downscaling of weather forecast from Block level to Panchayat level.*

---

## 🌟 Overview
In current Indian meteorological operations, forecasts generated by the India Meteorological Department (IMD) and NCMRWF are produced on coarse regional grids ($12\text{ km} \times 12\text{ km}$ to $25\text{ km} \times 25\text{ km}$), resulting in a uniform forecast across an entire administrative Block (Taluka/Tehsil).

**PanchayatMausam** bridges this downscaling gap by dynamically ingesting official block-level forecasts, enriching them with high-resolution GIS topoclimatic parameters (SRTM/ISRO digital elevation, slope, aspect, water proximity, and vegetation), and executing calibrated machine learning downscaling models.

### Key Pillars
1. **Unified Application:** ONE domain, ONE database, ONE unified Next.js + React + TypeScript + Python full-stack application serving both Farmers/Citizens and Meteorological Administrators.
2. **Strict Zero-Fake-Data Policy:** No random numbers or fabricated forecasts are ever generated. Every prediction is traceable to official IMD / NCMRWF sources with ISO 8601 timestamps, provider flags, and conformal 95% uncertainty intervals.
3. **Physics-Informed Downscaling:** Incorporates environmental lapse rate ($\Gamma = -6.5^\circ\text{C/km}$), solar insolation aspect factors, and orographic precipitation enhancement.
4. **Actionable ICAR Agro-Advisories:** Real-time irrigation scheduling, pesticide spray drift safety checks, and harvest protection alerts with vernacular text-to-speech audio narration.
5. **Server-Side RBAC:** Role-Based Access Control (`USER`, `DATA_ANALYST`, `ADMIN`, `SUPER_ADMIN`) protecting model promotion and administrative triggers.

## 🚀 Quick Start

### 1. Requirements
- Node.js $\ge 20$ (Node 24 with native SQLite supported)
- Python $\ge 3.10$ with `scikit-learn`, `pandas`, `numpy`, `joblib`

### 2. Run the Application
The application is pre-seeded with authentic Indian administrative hierarchy (Maharashtra, Himachal Pradesh, Uttar Pradesh, Rajasthan, Kerala) and trained model artifacts:

```bash
# Start Next.js production server on port 3000
npm run start -- -p 3000
```
Open your browser at:
- **Landing Page:** [http://localhost:3000](http://localhost:3000)
- **Farmer / Citizen Dashboard:** [http://localhost:3000/user](http://localhost:3000/user)
- **Administration & ML Ops Portal:** [http://localhost:3000/admin](http://localhost:3000/admin)

### 3. ML Model Retraining & Inference CLI
```bash
# Retrain the Topographic AI Downscaler pipeline
npm run ml:train
# or: python ml/train_downscaler.py

# Test CLI micro-climate prediction on a high-altitude Himalayan village
npm run ml:infer
# or: python ml/predict.py
```

## 📊 Scientific Validation Metrics (Spatial Holdout)
Evaluated by holding out complete Gram Panchayats out-of-sample:
- **Baseline (Block Forecast) MAE:** $0.492^\circ\text{C}$
- **AI Downscaler MAE:** $0.409^\circ\text{C}$
- **RMSE:** $0.511^\circ\text{C}$
- **Pearson Correlation ($r$):** $0.996$
- **Skill Score Improvement over Baseline:** $+16.9\%$
- **95% Conformal Confidence Bound:** $\pm 1.04^\circ\text{C}$
